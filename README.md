# AgriDirect Professional Website

A complete static prototype for the Smart India Hackathon 2026 farmer-to-market concept.

## Included
- Responsive professional dashboard
- Direct marketplace with search, category and buyer-mode filters
- Cart and demo checkout with escrow status
- Farmer/FPO onboarding and producer directory
- Indicative fair-price advisor
- Orders, filtering, search and tracking modal
- AI demand scenario visualization
- Logistics route comparison and dispatch modal
- Voice assistance using browser Speech Synthesis when available
- LocalStorage persistence for products, cart and orders
- Mobile navigation and keyboard focus states
- Safer static Node server path handling and security headers
- No decorative emojis in the UI

## Run
```bash
npm start
```
Open `http://localhost:3000`.

## Verify
```bash
npm run verify
```

This project is a frontend/demo implementation. Real payments, escrow, live market rates, identity verification, maps, IoT telemetry and AI predictions require production APIs and authenticated backend services.
