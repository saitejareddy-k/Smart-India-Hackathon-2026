# Rewrite Manifest

This release replaces the previous fragmented page styling and duplicated inline UI with a shared design system and consistent interaction model.

## Major fixes
- Removed decorative emojis and emoji-only controls.
- Removed duplicated theme declarations and conflicting marketplace inline CSS.
- Added one responsive design system for all pages.
- Added mobile navigation.
- Added accessible labels and focus-visible states.
- Added robust LocalStorage handling for cart/products/orders.
- Added safe HTML escaping for assistant input.
- Added bounded cart quantities.
- Added working search/filter interactions.
- Added order tracking and protected-settlement messaging.
- Added working farmer onboarding and harvest publishing flows.
- Added working AI scenario chart.
- Added working route comparison and dispatch workflow.
- Hardened the static Node server against path traversal.
- Added useful security response headers.
- Added reduced-motion support.
- Clearly labeled demo economics and prototype AI data to avoid presenting simulated values as live facts.
